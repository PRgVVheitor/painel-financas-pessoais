# Painel de Financas Pessoais

Dashboard simples para acompanhar entradas, gastos e categorias usando HTML, CSS e JavaScript puro.

## Objetivo

Criar um projeto inicial de portifolio com visual profissional, dados dinamicos e codigo facil de explicar em uma entrevista.

## Demo

Link: https://prgvvheitor.github.io/painel-financas-pessoais/

## Funcionalidades

- Resumo de saldo, entradas, saidas e economia.
- Lista de transacoes renderizada via JavaScript.
- Cadastro de novas transacoes.
- Remocao de transacoes.
- Persistencia com `localStorage`.
- Filtro por categoria.
- Busca por descricao.
- Barras de gasto por categoria.
- Destaque para a maior despesa do mes.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como rodar

Abra o arquivo `index.html` no navegador.
